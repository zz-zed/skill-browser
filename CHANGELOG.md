## [0.1.0] - 2026-08-12

### Added

- Initial public repository layout for the `skill-browser` Agent Skill.
- Read-only local Skill discovery for Codex and Claude Code roots.
- Detail, option, comparison, lexical search, and recommendation-candidate commands.
- Symlink deduplication, same-name conflict reporting, bounded reads, and reference path containment.
- English and Simplified Chinese documentation, unit tests, and CI validation.

### Changed

- Expand the English-first bilingual README into a complete repository overview.
- Add three shared README illustrations covering project value, evidence flow, and the trust boundary.
- Replace real third-party Skill examples with fictional names throughout public documentation.
