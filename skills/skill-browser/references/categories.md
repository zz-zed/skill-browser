# Navigation categories

Use these categories as navigation judgments, not as official Skill metadata.

## Capability map

- **Diagram and process**: relationships, flows, architecture, sequence, Draw.io, or other structured diagrams.
- **Visual and media**: raster images, illustrations, comics, infographics, video, or visual design.
- **Documents and office**: documents, spreadsheets, slides, PDFs, formatting, or publishing.
- **Product and business**: PRDs, analysis, reporting, planning, metrics, or operational workflows.
- **Browser and automation**: browser control, website interaction, deployment, setup, or recurring operations.
- **Knowledge and communication**: search, knowledge management, writing, editing, summarization, or messaging.
- **Development and quality**: coding, repository work, testing, review, debugging, migration, or security.
- **Other**: use only when source evidence does not support a clearer category.

Put each Skill in one primary category on the first screen. Mention secondary uses only on its detail page.

## Unified option groups

- `visual`: style, theme, palette, art treatment, tone.
- `structure`: layout, diagram type, hierarchy, composition.
- `output`: aspect ratio, format, scale, size.
- `runtime`: backend, provider, engine, model.
- `input`: reference material, language, accepted input.
- `recommendation`: documented presets or combinations.
- `advanced`: other documented flags and configuration.

Preserve source option names exactly. A translated label, quality rating, or suitability explanation is a navigation judgment unless the source provides it.
